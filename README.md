# Уровни игры

Данные уровней и редактор для телефона. Этот репозиторий заполняет Unity
(Tools → Levels → GitHub → «Отправить на GitHub»), руками здесь ничего не правится.

* `data/Level_NN.json` — уровни, `data/Progression.json` — открытия способностей и бонусные уровни,
  `data/schema.json` — справочники для редактора (типы заданий, способности, награды).
* `index.html`, `manifest.webmanifest`, `sw.js`, иконки — редактор (GitHub Pages).

## Телефон

1. Откройте страницу GitHub Pages этого репозитория: `https://<владелец>.github.io/<репозиторий>/`.
2. Добавьте её на главный экран:
   * Android, Chrome: меню ⋮ → «Установить приложение» (или «Добавить на главный экран»);
   * iPhone, Safari: «Поделиться» → «На экран Домой». На iPhone это обязательно — иначе Safari может стереть
     данные страницы, если её не открывать 7 дней.
3. Откройте приложение → «Настройки» → вставьте токен → «Сохранить». Уровни загрузятся.

Токен: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new
token; Repository access — только этот репозиторий; Permissions → Contents — Read and write. Токен хранится только
на устройстве, в репозиторий не попадает.

Правки сохраняются на телефоне (и без сети). «Отправить» — одним коммитом на GitHub; Unity забирает их через
«Получить с GitHub». Изменено одно и то же в двух местах — конфликт: выберите «Взять с GitHub» или «Оставить мои».
Удалять уровни — только в Unity.
